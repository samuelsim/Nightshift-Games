## Remaining scope and limitations

The docs explicitly defer factual Estimate trivia, difficulty settings, daily challenges,
persistent personal bests/statistics, custom decks, richer Human.exe deduction/voting,
extra bluffing roles, voice chat, and public matchmaking. These remain unimplemented;
they are not silently counted as delivered by this review.

A temporary host drop still holds host-only controls for up to the documented 120-second
window. Local countdown controls use the browser clock, so clock skew can differ from the
authoritative server deadline. Neither policy is changed in this pass.

There is no measurable art-density or animation-count target in the repository docs.
Existing themed illustrations and sound palettes meet the described treatment; further
subjective polish and real-device listening/playtesting remain useful.
